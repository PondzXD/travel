# V11 — Nearby Shops + Shop Admin

## หน้าเว็บไซต์

เมื่อกดสถานที่ → หน้า Detail

จะมีปุ่ม:

```text
🛍️ ร้านค้าใกล้เคียง
```

เมื่อกด:
1. แสดงร้านค้าที่ผูกกับสถานที่นั้น
2. กดร้านค้าเพื่อดูรายละเอียด
3. รายละเอียดร้านแสดงคล้าย Detail สถานที่
4. มีรูป / Gallery
5. ประเภทร้าน
6. รายละเอียด
7. สินค้า / บริการ
8. ช่องทางติดต่อ
9. เวลาเปิดปิด
10. คะแนนรีวิว
11. Google Maps
12. ปุ่มย้อนกลับไปยังสถานที่เดิม

## Admin

เปิด:

```text
admin.html
```

Login:

```text
Username: admin
Password: admin1234
```

เมนูหลังบ้าน:

```text
📍 สถานที่
＋ เพิ่มสถานที่
🛍️ ร้านค้า
＋ เพิ่มร้านค้า
```

## ร้านค้า

ร้านหนึ่งสามารถเลือกได้ว่าอยู่ใกล้สถานที่ใดบ้าง

ตัวอย่าง:

```js
nearbyPlaceIds: [
  "thale-noi",
  "napokae"
]
```

ร้านนั้นจะปรากฏในร้านค้าใกล้เคียงของทั้งสองสถานที่

## ข้อมูลร้าน

รองรับ:

- ชื่อ TH / EN
- ประเภทร้าน TH / EN
- ผูกกับสถานที่หลายแห่ง
- รายละเอียดร้าน
- สินค้า / บริการที่ขาย
- ที่อยู่
- เบอร์โทร
- Facebook
- LINE
- Website
- เวลาเปิด
- เวลาปิด
- คะแนน
- จำนวนรีวิว
- Latitude / Longitude
- Google Maps URL
- Google Maps Embed URL
- รูปหน้าปก
- Gallery หลายรูป
- เปิด / ปิดการแสดงร้าน

## Demo storage

ข้อมูลร้านเก็บที่:

```text
localStorage:
travel_demo_shops
```

ข้อมูลสถานที่:

```text
travel_demo_places
```

ใช้สำหรับ Demo เท่านั้น หากใช้งานจริงควรย้ายไป Firestore / Storage
