# V12 — Product Detail + User Reviews

## เพิ่มในร้านค้า

รายละเอียดร้านจะแสดง:
- คะแนน
- จำนวนรีวิว
- รายการสินค้า
- รูปสินค้า
- ชื่อสินค้า
- ราคา
- รายละเอียดสินค้า

## Admin ร้านค้า

ในฟอร์มร้านค้าเพิ่มหัวข้อ:

```text
สินค้าในร้าน
+ เพิ่มสินค้า
```

สินค้าแต่ละตัวมี:
- ชื่อ TH
- ชื่อ EN
- ราคา
- รูปสินค้า
- รายละเอียด TH
- รายละเอียด EN

## User Review

เฉพาะผู้ใช้ที่ Login แล้วเท่านั้นที่สามารถ:
- เลือกดาว 1–5
- เขียนรีวิว
- แชร์ประสบการณ์
- แก้รีวิวเดิมของตัวเองโดยส่งใหม่

รีวิวแสดง:
- Username
- ดาว
- ข้อความ
- วันที่
- ค่าเฉลี่ยรีวิว
- จำนวนรีวิวจากผู้ใช้

ข้อมูลรีวิว Demo เก็บที่:

```text
localStorage:
travel_demo_reviews
```

หมายเหตุ:
ระบบนี้เป็น Demo Front-end
หากใช้งานจริงควรย้าย Reviews / Products / Users ไป Firestore
