# V13 — แก้รีวิวร้าน + ร้านค้าโปรด

## รีวิวร้านค้า

แก้ระบบให้รีวิวแสดงในหน้า Detail ร้านค้าแล้ว

เมื่อเปิดร้านจะเห็น:

- คะแนนร้านเดิม
- จำนวนรีวิวเดิม
- จำนวนรีวิวที่สมาชิกเขียนในเว็บ
- รายการรีวิวสมาชิก
- Username
- คะแนน 1–5 ดาว
- ข้อความ
- วันที่

หากยังไม่มีรีวิวจะแสดง:

```text
ยังไม่มีใครรีวิวร้านนี้ คุณสามารถเป็นคนแรกได้
```

## วิธีทดสอบ

1. Sign up / Sign in User
2. เปิดสถานที่
3. ร้านค้าใกล้เคียง
4. กดร้าน
5. เลื่อนลงหัวข้อ "รีวิวจากผู้ใช้"
6. เลือกดาว
7. เขียนข้อความ
8. ส่งรีวิว

User เดิมส่งใหม่ = อัปเดตรีวิวเดิม

## ร้านค้าโปรด

เพิ่มหัวใจ ♡ ให้ร้านค้าแล้ว

มีทั้ง:
- บน Card ร้าน
- ใน Detail ร้าน

ถ้ายังไม่ Login แล้วกดหัวใจ:
ระบบจะเปิด Sign in

หลัง Login:
ร้านจะถูกบันทึกใน:

```text
localStorage:
travel_demo_shop_favorites
```

และในหัวข้อ "รายการโปรด" จะแสดงเพิ่ม:

```text
สถานที่โปรด
ร้านค้าโปรด
```

แยกกันชัดเจน
